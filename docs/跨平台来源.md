## 二、这一轮真正新增的两个来源

### 2.1 dsh-whale-galgame：5 张模型娘立绘

一个面向 DeepSeek Harness 的开源 Galgame 插件。它自带 22 张图片，其中第 12–16 号是**为 Claude / GPT / Gemini / Kimi / Grok 五个角色各画的一张立绘**，全部 1024×1536、透明底、画风统一。

**授权是这批素材里最清晰的**：

- 该链路整体以 **CC BY-NC-SA 4.0** 发布
- `NOTICE.md` 有**逐文件来源表**（22 个文件每个都写了来源与改动）
- 明确声明「Unofficial XXX-inspired, AI-assisted project artwork」「does not reproduce an official character design or exact logo」
- 明确要求：保留完整署名、仅限非商业、衍生以相同协议共享

这五张**不能进主表**（画风与 ZipZipPipe 体系不同，并列会破坏主表的横向可比性），但正好是画廊最该收的东西：同一批角色，另一套视觉语言。

### 2.2 TreapGoGo/deepseek-whale-girl：3 张带明确授权的三视图

618 星的社区鲸鱼娘资源库，有 `site/assets/gallery/manifest.json` 逐图记录 150 件作品（作者、来源、创作类型、尺寸、像素哈希）。

关键发现：**150 件里只有 3 件标了明确许可**——「大肥鱼三视图 · 长裙版 / 女仆版 / 蕾丝裙版」，作者**世界猫**，标注 `CC BY-NC-SA 4.0`，上游写明 ZipZipPipe / 上善无形。

这三张是标准的**正面 / 侧面 / 背面三视图**，质量很高，正好补上主表对象「只有立绘、没有设定稿」的空缺。

## 三、为什么大部分没有收

| 障碍 | 涉及数量 | 具体表现 |
| --- | --- | --- |
| **没有许可字段** | TreapGoGo 147 件、AATINF 202 张、dsh-deep-whale 87 张 | 仓库本身是 MIT，但 README 明确写「角色设定图、社区投稿及外部项目素材**不包含在上述代码许可中**，使用前请先核实对应许可」 |
| **许可为 NOASSERTION** | dsh-deep-whale | 有 LICENSE 文件但 GitHub 无法识别为任何标准协议 |
| **作者未知** | TreapGoGo 里以「作者未知」署名的一批 | 连署名都没有，与站内那 1040 件同理 |
| **平台不可批量取** | pixiv 站内搜索、X、微博、小红书 | 需要登录、有反爬，且授权更难溯 |

**这里有一个容易踩的坑**：仓库标了 MIT，不等于仓库里的图片也是 MIT。代码许可与素材许可是两件事，前者宽松不代表后者可以随便用。dsh-whale-galgame 之所以能收，正是因为它**把两者分开写清楚了**，还给了逐文件表。

## 四、这一轮暴露的生态规模

技术拟人不是零散的同人图，已经形成了有分工的开源生态：

| 层次 | 代表 | 规模 |
| --- | --- | --- |
| **角色原型** | 上善无形的「溟月」 | 单一 OC，CC BY-NC-SA 4.0 |
| **二次设计** | ZipZipPipe 的女仆鲸鱼娘 | 主表 31 张 + 画廊 16 张 |
| **资源库 / 索引** | TreapGoGo/deepseek-whale-girl | 150 件、41 位作者 |
| **素材扩展包** | AATINF/deepseek-whale-girl-assets | 202 张 |
| **皮肤 / 桌宠** | Small-tailqwq/dsh-deep-whale（2917★）、vlln/whale-girl（388★）、Sutera-Diffusus/dsh-whale-musume（176★） | 十余个插件 |
| **应用层** | dsh-whale-galgame（Galgame）、dsh-meme-hub（表情包）、[deepseek-chan-meme-pack](https://github.com/the-beating-light-of-the-nail/deepseek-chan-meme-pack)（126★）、[deepseek-chan-emotes](https://github.com/BrickAZ/deepseek-chan-emotes)（47★，161 个 GIF）、[dsh-nekowhale-stickers](https://github.com/Loping151/dsh-nekowhale-stickers)（72★） | 各自带图 |
| **百科** | 萌娘百科 DeepSeek娘 条目 | 记录形象演变史 |

**但极度集中在一个对象上。** 这 558 张图（TreapGoGo 269 + AATINF 202 + dsh-deep-whale 87）里，几乎全是 DeepSeek 鲸鱼娘。其他模型娘的图，仍然主要散落在各个画师的个人主页里，没有形成同样的社区规模。

这也是为什么主表坚持「一对象一张」——如果按图的数量排，DeepSeek 会占掉整个仓库。

## 五、下一步还能往哪走

| 方向 | 具体做法 | 预估 |
| --- | --- | --- |
| **追画师主页** | 从 TreapGoGo 的 41 位作者里挑有 pixiv/B站 账号的，逐个看其作品集 | 中，需人工判断 |
| **盯新发** | dsh 生态每周都有新插件，新插件常带新立绘（如 galgame 这次） | 高，但要持续 |
| **开源素材仓** | 搜 `whale-girl` / `AI娘 assets` / `character-sheet` 类仓库，重点看有没有逐文件许可表 | 中 |
| **百科反查** | 萌娘百科每个角色条目都会列代表画师与 pixiv ID，是找源头的捷径 | 高，但条目不全（目前只有 DeepSeek娘） |
| **授权确认** | 对已登记但无许可的素材，通过 issue 联系维护者或作者补许可 | 低，但一旦成功价值最高 |
