本文件逐图记录 **29 件作品**（22 张统一风格立绘 + 7 件其他角色作品）的确切来源、原图路径、尺寸、创作者署名与授权状态，并说明三类主体的分工，以及使用前的注意事项。其中 22 张统一风格立绘随本仓库发布；7 件其他角色作品因**规格不符统一风格、且作者归属更混杂**，**未随本仓库发布**，但来源信息在此完整保留、逐条可查。

## 一、来源链路

所有图片都源自同一个站点 —— **蓝色大肥鱼**（`https://xn--pssy23gqgbz2d718b.com`）的 AI 娘二创图库。链路如下：

```
蓝色大肥鱼 站点（作品页 /works/<作品ID>.html）
        │  页面 <script type="application/ld+json"> 中的 ImageObject 节点
        │  contentUrl → /submissions/large/<role>/<hash>.webp
        ▼
站点图仓 GitHub 仓库：lmy414/ai-girl-stickers
        │  目录 dist/submissions/originals/<role>/<hash>.<ext>
        │  ← 文件名 hash 与 contentUrl 中的 hash 完全一致，构成唯一映射
        ▼
本仓库（经整幅下载 + 完整性校验 + 白底/全身风格检测后收录）
```

**hash 三重同源**：`站点预览图文件名` = `图仓原图文件名` = `作品页 contentUrl 中的 hash`。三者一致即可确认一张图的确切出处，无需人工比对画面。

原始 PNG/JPG 完整原图均取自 GitHub Raw 直链：

```
https://raw.githubusercontent.com/lmy414/ai-girl-stickers/main/dist/submissions/originals/<role>/<hash>.<ext>
```

> 说明：站点自身的 `/submissions/originals/...` 与 `/originals/...` 路径均返回 404，原图只经由 GitHub 仓库对外暴露。

## 六、溯源方法（可复现）

本仓库所有来源结论均可按以下流程复现：

1. **枚举作品页** —— 站点角色页形如 `/characters/<slug>.html`，分类子页形如 `/characters/<slug>/standing.html`，全站分页形如 `/page/N.html`（共 54 页）。抓取后共得到 **1287 件作品**。
2. **解析 JSON-LD** —— 提取每个作品页的 `ImageObject` 节点，取得 `contentUrl`、`creator`、`creditText`、`copyrightNotice`、`license`、`uploadDate`、`keywords`、`genre`。
3. **构建 hash 索引** —— 图仓 `dist/submissions/originals/` 下共 **1097 个原图**，以文件名为 key 建立 `hash → 作品页` 反向索引。
4. **下载并做完整性校验** —— 用 PIL `Image.open(f).load()` 检测下载截断（`image file is truncated`）；GitHub Raw 大文件下载中断时，改用 `git checkout HEAD -- <path>` 从 blob:none 部分克隆中取 blob。
5. **整幅相关度匹配** —— 64×64 灰度归一化后计算点积余弦相似度，与站点预览图比对，确认是否同一幅作品。**全过程不裁切、不切片、不做局部截取。**
6. **风格检测** —— 采样四角与四边中点像素均值（>235 判为近白），验证「白底」；再检测底部留白比例（53%~92%），验证「完整全身立绘」。

> 本次收录的 22 张主原画 **22/22 通过** 白底检测（边缘 8/8 近白）与完整全身检测，来源匹配相关度均为 **1.000（完全一致）**。
