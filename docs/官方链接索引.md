## 五、按用途快速跳转

**想了解模型架构与技术特性**
→ DeepSeek（MLA + MoE）、Qwen（混合思考 + MCP）、GLM（参数效率）、Kimi（agentic）、RWKV（线性注意力）五家的官方技术报告最能读懂 —— 它们各自代表一条不同的架构路线。

**想自部署 / 私有化**
→ Hugging Face（工具链）、Qwen 与 Mistral（开放权重小尺寸）、DeepSeek（MIT 许可 + 允许蒸馏）、GLM（MIT）、MiniMax（开放权重，部分带营收门槛）、ZCode（Apache-2.0）。

**想做编码 agent**
→ OpenCode（开源外壳）、ZCode（智谱工作台）、GitHub Copilot（平台原生）、GitLab Duo（DevSecOps 集成）。

**想了解检索增强 / 实时信息**
→ Perplexity（RAG 管线与引用机制）、Grok（社交平台实时流）。

**想找二次元风格图像生成**
→ NovelAI（Danbooru 训练的自研扩散模型）、豆包 Seed（图像模型矩阵）。
